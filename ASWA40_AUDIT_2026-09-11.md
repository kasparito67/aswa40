## Bugs found and fixed

### Data / section ranges

- `2000–2024`: full ranking label incorrectly started at `#25`; corrected to `#26–135` to match the data.
- `Biopics`: visual section said `TOP 15`, but the renderer could show 25 because no explicit count was set. The featured section is now explicitly 15 and the full ranking starts at `#16`.
- `Animation`: `LE...K` is removed and the list is reranked. OVNI bottom ranks were still based on the pre-rerank numbering and included nonexistent `#90`; corrected to current ranks `#85–89`.

### Data ownership

- `canonical-data.js` and `platform-config.js` both assigned Documentaires / Re.Watched presentation structure. `canonical-data.js` now owns durable identity locks only; `platform-config.js` owns section/presentation configuration.
- Icarus (TMDB 432976), Senna (TMDB 58496) and Home Alone (TMDB 771) remain locked.

### Desktop interaction

- Native desktop carousel motion now drives parallax during programmatic smooth scrolling, not only trackpad wheel input.
- Bottom Top selector closes on rail movement and owns its focused left/right keys so it cannot double-trigger the global navigation handler.
- Global page arrow keys no longer fire while focus is inside buttons, links or form/content-editable controls.
- Film-card trackpad direction now uses the accumulated signed horizontal gesture rather than whichever tiny inertial frame happens to cross the commit threshold.

### State / race conditions

- Rapid section open/close can no longer be overridden by a stale 540 ms height timer.
- `aria-expanded` now tracks section disclosure state.
- Repeated fast clicks on `Voir plus` are locked while a batch is loading, preventing duplicate film insertion.

## Architecture after audit

### Desktop

`bootstrap.js` selects desktop when `(min-width:701px) and (hover:hover) and (pointer:fine)` and loads:

- `app-desktop.js` — renderer, native horizontal scroll-snap rail, routes, sections and modal;
- `top-nav.js` — bottom direct Top selector;
- `parallax.js` — visual parallax synchronized to native rail movement.

All seven Top screens are mounted in the native horizontal rail. The browser owns horizontal momentum and snapping.

### Mobile / coarse pointer

`bootstrap.js` loads:

- `runtime.js` — focused mobile support;
- `app.js` — validated transform carousel, renderer, sections and modal;
- `parallax.js`, which exits early on mobile.

At rest the mobile carousel keeps one Top mounted and temporarily mounts an adjacent screen during transition.
